# Tirtharaj Dutta Roy | Engineering Portfolio

A high-fidelity, interactive portfolio built to showcase technical case studies in Machine Learning, System Utility, and Natural Language Processing. 

## ⚙️ Architecture & Tech Stack
* **Frontend Engine:** React 18 + Vite
* **Styling & Physics:** Native CSS3, custom mathematical normalized vectors, and CSS Spring Physics (No heavy animation libraries used to ensure 60fps performance).
* **Data Layer:** Local JSON mapping for instantaneous data delivery.
* **Visualizations:** Custom reactive SVG rendering for probability curves and NLP node tracking.
